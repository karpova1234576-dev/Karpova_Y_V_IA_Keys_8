# Генератор случайных паролей с оценкой сложности (Кейс 8)

Приложение на Python с графическим интерфейсом (tkinter): генерирует стойкие пароли,
оценивает их сложность и хранит в журнале в зашифрованном виде. У каждого пользователя
свой ключ и свой журнал паролей.

## Структура проекта
```
password_generator/
├── main.py              # графический интерфейс и точка входа
├── generator.py         # генерация паролей и оценка сложности
├── database.py          # SQLite: пользователи и журнал паролей
├── test_generator.py    # тесты генерации и оценки
├── test_database.py     # тесты пользователей и журнала
├── requirements.txt
└── passwords.db         # создаётся автоматически при первом запуске
```

## Как это работает
При запуске программа спрашивает **имя пользователя и ключ**:
- такого пользователя нет — создаётся новый (имя уникально, без учёта регистра);
- пользователь есть и ключ верный — открывается его журнал паролей;
- пользователь есть, но ключ неверный — ошибка (чужое имя занять нельзя).

При сохранении пароля спрашивается **ресурс** (сайт, сервис). Ресурс в журнале уникален:
если пароль для него уже есть, программа спросит, обновить ли его («Да» — обновит,
«Нет» — отмена). Журнал открывается в модальном окне и показывает только записи
текущего пользователя.

## Хранение и безопасность
| Таблица | Поля |
|---|---|
| `users` | `username` (уникальное), `salt`, `key_check` |
| `passwords` | `username`, `resource`, `password_enc`, `updated_date` (уникальны `username` + `resource`) |

- **Ключ пользователя в базе не хранится.** В `key_check` лежит контрольная строка,
  зашифрованная этим ключом: так программа проверяет ключ, а файл базы его не раскрывает.
- Пароли шифруются Fernet; ключ шифрования выводится из ключа пользователя через
  PBKDF2-HMAC-SHA256 (480 000 итераций) с индивидуальной солью. Ключ одного пользователя
  не расшифрует записи другого.
- Забытый ключ **восстановить нельзя**: без него записи не расшифровать.

## Установка и запуск
```bash
pip install -r requirements.txt
python main.py
```
Нужен Python 3.8+. На Linux при отсутствии tkinter: `sudo apt install python3-tk`.

## Алгоритм оценки сложности
1. Энтропия = `длина × log2(размер алфавита)`.
2. Штрафы: популярный пароль (в т.ч. `Password1!`, `P@ssw0rd2024`) ограничивается 10 битами;
   повторы символа подряд, последовательности (`abc`, `123`, `qwe`, в т.ч. русская
   раскладка), малая доля уникальных символов — по ×0.8 к энтропии.
3. `оценка = эффективная энтропия / 80 × 100` (не более 100).
4. Уровни по эффективной энтропии: <28 очень слабый, <40 слабый, <60 средний,
   <80 хороший, ≥80 отличный. Дополнительно выводятся подсказки по улучшению.

Ограничение: оценка не знает словарей, поэтому слово из обычного словаря с цифрами
(`Summer2024!`) она оценит выше, чем стоило бы.
